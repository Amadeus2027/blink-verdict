给眼前的选择，一个答案。BlinkVerdict 是一款原生 Windows 快捷键决策助手，在需要时读取当前屏幕，通过你配置的模型从指定选项中给出选择。

这是首个候选发行包，**不是稳定版**。未完成的验收项目见 [版本记录](https://github.com/Amadeus2027/blink-verdict/blob/codex/release-audit/docs/releases/0.1.0-rc.1.md)。

### 这版提供什么

- 透明文字全屏浮现，以及可拖动、缩放、独立调节背景透明度的常驻浮窗。
- 自定义目标、2–20 个答案、快捷键、显示时长、五种出现效果；三种内置 YES / NO 字效及透明 PNG。
- 专用决策协议、常规视觉/聊天协议，云端 API 和已启动的本机服务。
- 浅色分组设置、无需调用模型的外观预览、托盘暂停与状态信息。
- 原生 Rust、按需截图/OCR、Windows 凭据管理器存储密钥、无遥测或自动更新请求。

### 下载与运行

面向 Windows 10 22H2 / Windows 11 x64。下载 `blink-verdict-0.1.0-rc.1-windows-x64.zip`，核对 `SHA256SUMS.txt`，解压后运行 `blink-verdict.exe`；无需管理员权限。首次启动先配置模型，然后设置目标与答案，默认快捷键 Ctrl + Alt + Space。

更新时从托盘退出再替换程序。设置位于 `%LOCALAPPDATA%\BlinkVerdict`，并非与程序放在一起。包中含源码提交和 SHA-256 清单、MIT 许可及依赖声明。程序没有 Authenticode 签名，可能显示未知发布者。没有安装器、自动更新或其他架构包。

### 已知边界

- 真实模型服务、消费版 Windows 10/11、多显示器/DPI、长时间运行和实际游戏仍需验收。回环样例不能证明厂商在线服务可用。
- 没有已认证兼容的游戏。独占全屏、反作弊和受保护画面可能无法捕获或显示；Game Bar 是单独的实验组件，不包含在此包中。
- 浮窗为半透明表面；玻璃字效为预绘制图片，没有实时背景折射或模糊。
- 云端服务会收到本次画面或 OCR 文字、目标与选项。服务费用及数据留存由相应提供方决定，模型判断可能出错。

自动检查与资源测量结果以版本验收记录和对应 Actions 任务为准，不将短采样结果作为所有设备的占用承诺。
