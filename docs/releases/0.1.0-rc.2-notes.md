给眼前的选择，一个答案。BlinkVerdict 是一款原生 Windows 快捷键决策助手，让模型结合当前屏幕，从你给定的答案中做出选择。

**0.1.0-rc.2 是预览候选版。** 本次已通过完整 Windows CI 自动验收、实际 llama-server 文字接口测试、桌面快捷键/输入穿透、资源与发行包校验；尚未认证真实游戏和全部消费设备。[验收记录](https://github.com/Amadeus2027/blink-verdict/blob/main/docs/releases/0.1.0-rc.2.md) · [构建任务](https://github.com/Amadeus2027/blink-verdict/actions/runs/40161041424)

### 这次更新

- llama.cpp 独立本机预设，支持原生结构化选项；原有本地/API 接口全部保留。Ollama 默认遵循服务驻留策略。
- 判断任务超时或意外退出后恢复按键，无需因任务卡住而重启程序；平时不保留工作进程。
- 浮窗尺寸与字号随显示器 DPI 缩放，设置跨 DPI 重建时保留草稿；0% 背景在调整布局时仍可拖动。
- 全屏仍只显示文字或透明字效，绘制缓冲缩到结果范围；极小浮窗里的长答案也会缩放以完整显示。
- 修复“关于”页清空 Game Bar 配置、保存失败后密钥未恢复，以及旧收起操作清掉新结果的问题。
- 首次配置取消或加载失败时不会用默认云端服务启动判断。检测到 HDR／高级色彩时停止 GDI 截图并提示。

### 下载与运行

系统目标为 Windows 10 22H2 / Windows 11 x64。下载 ZIP，核对 `SHA256SUMS.txt`，解压运行 `blink-verdict.exe`；无需管理员权限。先连接模型并保存目标和选项，再按 **Ctrl + Alt + Space**。程序不附带模型权重。

ZIP 约 0.97 MB，主程序约 1.29 MB。CI 中使用后待命平均私有工作集约 2.21 MiB，浮窗约 5.12 MiB；条件和活动父子进程采样见验收记录，不是所有设备的占用承诺。

更新前从托盘退出，再替换程序；配置和 Windows 凭据管理器中的密钥另行保存。MIT 许可、依赖声明和来源摘要随包附带。程序没有 Authenticode 签名，Windows 可能显示未知发布者。旧 RC1 继续暂停发布，请使用此候选。

### 当前边界

- 自动化证据来自 Windows runner；实体双屏/HDR、真实游戏/反作弊、消费设备、用户 GGUF/视觉/GPU、OCR 语言包和长期耐久仍未认证。
- Game Bar 是单独安装的实验组件，不包含在此 ZIP；使用时必须与主程序一起更新到匹配的 v2 协议。当前没有已认证兼容的游戏。
- 浮窗为半透明表面，玻璃字效是预绘制图片，没有实时背景折射或模糊。
- 云端服务会收到本次画面或 OCR 文字、目标与选项。模型判断可能出错，服务费用和数据留存由相应提供方决定。
